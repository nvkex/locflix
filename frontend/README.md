# Locflix frontend

React + TypeScript (Vite) UI for Locflix — glass Netflix-style browse, detail, and player.

## Dev

```bash
npm install
npm run dev
```

Requires the backend on `http://127.0.0.1:8787`. Vite proxies `/api` there (see `vite.config.ts`).

## Scripts

| Command | Purpose |
|---------|---------|
| `npm run dev` | Dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |

Product docs live in the [repo README](../README.md) and [docs/DESIGN.md](../docs/DESIGN.md).
